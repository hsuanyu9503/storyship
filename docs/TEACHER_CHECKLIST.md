# 教師課前檢查表（故事找朋友，40 分鐘）

印出或在另一台裝置開著。每一項約 1 分鐘；全部做完約 10 分鐘。**任何一項不通過，先看右欄的處理方式。**

## 一、前一天（或第一次使用前）

| ✓ | 項目 | 怎麼確認 | 不通過時 |
|---|---|---|---|
| ☐ | 資料庫已升級到最新版本 | Supabase SQL Editor 執行 `supabase/checks/verify.sql`，17 列 `ok` 都是 `true` | 執行 `supabase/upgrade/upgrade.sql`（可重複執行、不會刪資料）後再檢查 |
| ☐ | 網站是最新版本 | 開啟網站，教師端登入後能看到 05「每頁 4／2／1 類」「放大此側」 | 確認 GitHub Pages 已部署 `main`；所有裝置重新整理（必要時清除快取） |
| ☐ | 教師帳號可登入 | 用上課要用的教師平板登入 | 依 `docs/DEPLOY.md` A-3 確認帳號已加入白名單 |

| ☐ | 正式素材已匯入 | 01、06 預覽內容是正式故事與小說類型 | 依 `docs/DEPLOY.md` D 節匯入 |

## 三、上課中要記得的事

* **05、07 先私下預覽，再按「公開到投影」**。按鈕顯示「預覽更新中…」時表示新預覽還沒回來，等一下再按。
* 公開後狀態列顯示「● 投影與預覽一致」才代表全班看到的就是預覽的內容。
* 預覽出現「⚠ 投影放不下全部內容」：把該側「每頁」改成 2 類或 1 類，或按「放大此側」；**不要**縮小瀏覽器。
* 07 顯示很長的共同特色時，可先關閉「句型鷹架」或不顯示理由。
* 用兩台裝置操作時：另一台公開後，這台若沒有修改，會自動跟著更新；若顯示「有尚未公開的變更」，代表這台有自己的修改，按「放棄變更」即可回到投影中的內容。
* 結束 03、04 時會詢問未完成的人數；按「返回等待」不會改變任何東西。
* 網路斷掉：學生畫面會顯示「尚未儲存」，恢復後自動補存；教師端顯示「離線」時先不要切換環節。

## 五、出問題時

| 狀況 | 處理 |
|---|---|
| 投影畫面停住 | 投影電腦重新整理（投影只讀伺服器狀態，不會遺失任何東西） |
| 學生畫面停住或顯示錯誤 | 該平板重新整理；身分與成果都會保留 |
| 教師端顯示「狀態已在其他裝置變更」 | 另一台教師裝置剛操作過；畫面已重新載入，再操作一次即可 |
| 網站更新後出現異常 | 請管理者依 `docs/DEPLOY.md` G 節把網站退回上一版（資料庫不需要動） |
