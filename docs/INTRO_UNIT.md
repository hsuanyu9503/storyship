# 第 01 環節「走進故事世界」：正式教材與操作

全班一起猜作品的投影活動，由老師一步一步操作：開場 → 神祕故事一（三條線索）→ 公布《名偵探柯南》→ 神祕故事二（三條線索）→
公布《神隱少女》→ 兩個故事放在一起（比較提問 → 命名提問）→ 接下來，換你分類 → 第 02 環節（分類任務啟動）→ 第 03 環節（故事卡分類）。

## 2. 資料（依 slug 一對一；id、slug、sort_order 不變）

| 欄位 | 內容 |
|---|---|
| `intro_stories`（intro-1、intro-2） | `title`＝作品名稱（不含書名號）、`reveal_text`＝揭曉說明、`name_before`／`name_after`（新增）、`image_url`、`image_alt`（新增） |
| `intro_clues`（每則 sort_order 1～3） | `label`＝「發生了什麼事？」等、`body`＝線索內文、`kind`＝other（原稿沒有分類）、不使用插畫 |
| `content_sets.intro_text`（新增，jsonb） | `opening`、`compare_title`、`compare_prompts`、`naming_prompt`、`bridge_title`、`bridge_text` |

這些資料只有教師讀得到（RLS），投影端只會收到教師端已公開的部分。舊資料（沒有新欄位或 `intro_text`）仍可使用：
開場顯示「有 N 個神祕的故事正在等待我們探索」、比較提問為「這些故事有什麼共同的特色？」、沒有命名步驟。

## 3. 揭曉時機與畫面

* 猜題時的投影資料只有中性名稱（神祕故事一／二）、已顯示的線索與「線索 n / 3」；作品名稱、角色名字、揭曉說明、圖片網址與替代文字
  都不在投影資料裡（所以投影畫面、頁面標題、圖片、替代文字、學生端都不可能出現答案）。頁面標題是場次名稱。
* 尚未顯示的線索位置留白（只有「線索三」等編號），線索出現時版面不跳動。
* 公布後：作品圖（替代文字如「《名偵探柯南》揭曉圖：工藤新一與江戶川柯南並肩思考」）、《作品》、甲 → 乙、揭曉說明；下方保留三條線索供對照。
* 從揭曉按「上一步」：回到三條線索，圖片與答案一起收起。從神祕故事二的開頭按「上一步」：回到神祕故事一的揭曉畫面。
* 投影頁在直向或窄視窗（寬 ≤ 高）時，01 的畫面不再固定 16:9，改為依內容延伸、可捲動，字級有下限（線索 20px）。16:9 與 4:3 投影維持原本的 16:9 版面。

## 4. 老師操作（教師主控台）

* 一個主要按鈕，文字就是下一步要做的事：「開始：神祕故事一」→「顯示下一條線索」×3 →「公布作品」→「進入神祕故事二」→ … →
  「兩個故事放在一起」→「下一個提問」→「接下來，換你分類」→「進入下一環節：分類任務啟動」。旁邊是「← 上一步」（剛好撤銷一步）。
* 每按一次只前進一步；送出期間再按會被忽略。前進成功後有 0.7 秒冷卻（主要按鈕暫時停用），同一次快速雙點的第二下、鍵盤連按都不會跳過揭曉頁。不自動倒數、不自動跳頁。
* 鍵盤或簡報筆：→／PageDown 下一步、←／PageUp 上一步（焦點在輸入欄位或有對話框時不作用；按住不放不算）。與主要按鈕是同一個動作：在轉場頁按 → 或 PageDown 會進入 02。
  由轉場頁進入 02 後的 0.7 秒內，環節切換按鈕的點擊會被忽略（避免雙點連續切換兩個環節）。
* 下一步也不會讓比較題提前出現：比較提問與命名提問會提到兩部作品的主角，所以只有兩部都公布後才投影。舊場次停在只公布一部的交會畫面時，下一步進入另一則的中性猜題頁（線索從零開始），由老師逐條顯示並公布；只公布第二則時，補完第一則後直接進入比較。
* 上一步只會收起答案，不會公布新的作品：舊場次（舊版可只公布第一則就進入交會畫面）返回時，回到實際已公布的那一則；沒有任何已公布紀錄時回到開場。
* 「略過，直接進入下一環節」保留給需要跳過活動的情況。

## 5. 更新與回復（請在沒有課堂時進行；見 `DEPLOY.md` J 節）

## 6. 需要人工確認的項目

1. 揭曉圖的替代文字（兩句）是開發者依圖片內容撰寫，原稿沒有提供。
2. 猜題畫面沒有另加提示句（舊版的「這是什麼故事呢？」已移除），開場語已包含提問；若希望猜題時再提醒，請提供文字。
3. 比較畫面的兩行名字在 16:9 投影上會在箭頭處換行（例如「工藤新一 →」／「江戶川柯南」）。
4. 圖片與作品內容的授權、使用範圍沒有查核。
5. 實體投影機（亮度、對比、後排可讀性）、實體平板與簡報筆尚未實測；所有結果都是瀏覽器模擬。
